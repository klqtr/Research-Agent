# AI 协同与 Prompt 审计

本项目由用户提出需求、提供官方赛道链接并授权自主研发；Codex 执行规则读取、架构设计、实现、下载公开数据、运行实验与修复。未调用其他研究团队、未虚构人类分工。参赛者需亲自理解代码并决定最终提交。

模型提示词与原生工具schema在 `src/model.py:SYSTEM/plan_native/finish_native`；`src/planner.py`保留JSON计划校验函数及确定性路由，翻译系统提示在 `src/app.py`，均可审查。文献内容被视为不可信数据；规划只可选择白名单工具，拒绝额外参数、任意网络URL及代码执行。规划与生成分别受结构化输出、步骤数及引用约束。

调优记录：初版关键词+字符RRF会返回弱相关证据，加入停用词和词项资格门槛；开发集硬件段落召回不足，加入可解释的数字设备信息重排；新论文集在此后冻结检索算法运行，未根据其失败项继续调参。真实扫描测试暴露OCR路径问题、真实教材暴露参考文献被误当自身arXiv身份问题，均追加回归测试。

没有真实模型端点，因此未执行 Prompt 效果对比、原生Function Calling真实效果、LLM翻译/生成质量测评。MockTransport 只用于测试超时、错误JSON、用量字段解析，测试文本不作为真实模型输出。

本文件不等于完整AI对话历史。用户可保留本聊天记录作为补充审计材料，最终按官方要求确认提交范围。
