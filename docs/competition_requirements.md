# 官方要求核验（2026-10-16）

## 证据与范围
用户指定：[官方详情](https://www.boxuegu.com/matchTrack/detail/?id=10040)。正文由公开接口 `https://gateway.boxuegu.com/portal-marketing/competition/track/detail?id=10040&includeDetail=true` 提供，接口从官方客户端脚本确认；原始字节存档 `sources/official_track_raw.json`，可读正文 `sources/official_rules.txt`。首次 PowerShell 解码存档包含乱码，不作为规则证据。高校摘要仅为寻找入口，最终以主办方正文为依据。

## 官方明确要求
1. 命题为“智领科研·意图驱动：基于大模型与 Agent 架构的全流程科研助手构建挑战赛”，不是自由选题。要求融合 LLM 与 Agent 的全栈 Web 应用，前后端闭环。
2. 六个必需模块：PDF CRUD/内容语义去重/多模态细粒度解析；带原文锚点的单篇与跨篇 RAG；原生版式阅读/引用双向跳转/中英联动翻译；搜索下载/动态追踪/个性推荐；引用图谱/基石节点/综述与 Future Work 去旧；写作框架/真实参考文献/拓扑脚本/CSV 图表/学术翻译。
3. 必须兼容官方 `pdf/`：Attention v1/v7 内容去重、扫描版本 OCR、541 页 Understanding Deep Learning。当前目录没有该资料包，尚未取得官方预置样本。
4. 可以使用商业大模型 API，费用自担；鼓励开源或本地轻量模型，没有强制本地部署，也没有强制指定框架。技术栈表是推荐，不是强制。
5. 允许并鼓励 AI 辅助编程；选手必须理解核心架构，在技术文档说明 AI 协同贡献及 Prompt 调优策略。
6. 个人赛；学籍/组别按官方表核验，禁止虚假报名、抄袭和侵权。
7. 提交 GitHub/Gitee（公开或评审权限）、真实完整 Git 历史、清晰代码、README（含介绍/架构/运行/团队）、环境变量模板和依赖；密钥不得公开。
8. 演示视频 MP4，5–8 分钟，至少 1080p，普通话；技术文档 PDF，不超过 30 页，含概述/需求/架构/AI 方案/实现/测试部署/展望/创新说明。
9. 必须提供公网在线演示，评审期可用，需要登录则提供测试账号。提交通过官网；提交后不得修改，特殊情况联系组委会。
10. 省赛报名及作品截止 2026-11-18；国赛正文列作品截止 2026-12-27、报名 12-10 至 12-21。与高校校赛日期不混同。
