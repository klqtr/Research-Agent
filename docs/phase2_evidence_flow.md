# 核心算法流程（实际实现）

```mermaid
flowchart TD
 Q[用户科研问题与选定文献] --> I[规则意图提示/最多3标点子问题]
 I --> V[latest/all/explicit版本策略]
 V --> M{明确启用且有授权模型配置?}
 M -->|否| D[确定性标题检索/版本检查/证据提取]
 M -->|是| B[共享预算预留/上下文安全上限]
 B --> L[模型选择工具或输出JSON断言]
 L --> T{有原生工具调用?}
 T -->|有| A[严格参数/当前文献权限/可选联网权限]
 A --> E[执行只读工具/错误也返回tool消息]
 E --> J[保存状态/完成ID/累计次数]
 J --> R{4回合/6工具内?}
 R -->|是| B
 R -->|否| D
 T -->|无| C[引用ID与原文完整性]
 D --> C
 C --> S[独立保守支持关卡/来源版本检查]
 S --> F{完整来源表述可发布?}
 F -->|是| O[回答附原页/块/bbox与模式]
 F -->|否且尚未修复| P[一次模型修复或删除断言]
 P --> B
 F -->|否且已修复/无模型| N[拒答或原文候选供复核]
```

图中I为已披露的规则提示，不是LLM推理。B累计所有实际请求尝试（包括失败和重试），费用未知保持null。S仅对完整原文表述作窄范围支持，不是通用语义蕴含；数值/版本差异是待核验候选。

真实模型不可用或预算超限不会发布模拟回答。无原生工具时可降为确定性RAG+真实JSON综合，并明确标记兼容模式。恢复要求同源指纹与权限、有效租约；完成记录只读返回，不重新计费。
