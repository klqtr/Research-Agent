# 创新与证据状态

|设计|可验证假设|对照|限制|
|---|---|---|---|
|版本家族与证据引用统一|避免旧版静默覆盖与错误定位|文件名去重/正文去重|词汇相似并非深层语义|
|按论文分配检索配额|提高跨篇证据覆盖|融合无配额/融合有配额|可能牺牲单篇最高相关块|
|原文 quote + 块ID校验|降低伪造引用接受率|无校验/开启校验|不能独立证明语义蕴含|
|图谱辅助综述与未来问题核验|使综述来源与假设状态可检查|平铺文献列表|不宣称自动证实科研新颖性|

当前为待实现/待实验假设；最终状态与数值以 reports 和 experiments 的运行记录为准。没有模型真实推理时，不报告 LLM 准确率、Token 成本或生成质量。
